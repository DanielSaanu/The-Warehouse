# shared/ — syncs to `ReplicatedStorage.Shared`

Pure Luau: no Instances, no Roblox APIs, deterministic given an `Rng`. That's what lets `npm run test:luau` run it
outside Studio, and it's a hard rule (CLAUDE.md). Changing anything here is escalation trigger 2. The one
exception is `Sprites.lua`, which is GENERATED by `node bin/warehouse.js roblox build`. Never edit it by hand.
